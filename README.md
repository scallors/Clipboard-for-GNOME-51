# Clipboard-for-GNOME-51
A clipboard for GNOME's top bar which stays in the system tray to reduce clutter


1) Have extension manager installed
2) Go to your folder where you downloaded the zip file in
3) Open terminal inside that folder (Ctrl + .)
4) Run : gnome-extensions install --force "clipboard-qs@local.zip"
5) Log out and log back in
6) Enable the extension from extension manager
